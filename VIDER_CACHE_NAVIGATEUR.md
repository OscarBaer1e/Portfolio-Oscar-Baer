# 🧹 Vider le cache du navigateur

## ⚠️ Pourquoi vider le cache ?

Si vous voyez encore des erreurs Firebase, c'est probablement parce que votre navigateur a mis en cache les anciens fichiers qui contenaient Firebase.

## 🚀 Solution rapide

### Sur Mac (Chrome/Edge/Firefox) :

1. **Ouvrez votre site**
2. **Appuyez sur** : `Cmd + Shift + R` (rechargement forcé)
   - Ou `Cmd + Shift + Delete` → Effacer les données de navigation → Cocher "Images et fichiers en cache" → Effacer

### Sur Mac (Safari) :

1. **Menu** → **Développement** → **Vider les caches**
2. Ou `Cmd + Option + E`

## 🔍 Vérification

Après avoir vidé le cache :

1. **Rechargez la page** : `Cmd + Shift + R`
2. **Ouvrez la console** : `Cmd + Option + I`
3. **Vérifiez** : Plus d'erreurs Firebase !

## ✅ Si ça ne fonctionne pas

1. **Fermez complètement le navigateur**
2. **Rouvrez-le**
3. **Rechargez la page** : `Cmd + Shift + R`
