MEME-ORY – Images des cartes
============================

Fichiers attendus : meme1.png, meme2.png, … meme16.png (noms en minuscules, extension .png).

Pour que les images s’affichent en ligne (autre PC, GitHub Pages, etc.) :

1. Ces fichiers doivent être bien présents dans ce dossier et versionnés (git add + commit + push).
2. Le dossier doit s’appeler exactement "ressources" (minuscules) à la racine du projet.
3. Ne pas ignorer ce dossier ou les .png dans .gitignore.
4. Le site doit être ouvert via une URL (http ou https), pas en ouvrant le fichier HTML en local (file://).
5. En cas de 404 : vérifier l’URL des images dans l’onglet Réseau (F12) et que le chemin correspond à la structure du site en ligne.
