TXLFORMA – Site de vente de formations

Design UI/UX React · Stripe · Spring Boot Blender 3D

Objectif du projet

TXLFORMA est une plateforme de vente de formations combinant une interface web moderne, une salle de classe entièrement modélisée en 3D et un back-end robuste pour la gestion des utilisateurs, sessions et paiements.

Modélisation 3D – Blender

  • Modélisation complète d’une salle de classe (tables, chaises, PC, portes, fenêtres) à partir de photos, de tutos et d’imagination.
  • Création et ajustement des textures via l’outil Shading, avec bake pour optimiser les performances en temps réel.
  • Création d’animations (caméras, éléments de la salle) pour enrichir l’expérience utilisateur.
  • Intégration de la scène 3D dans le site web, avec contrôles interactifs (rotation, zoom, déplacement).

Front-end – React & Stripe

  • Conception de la maquette UI/UX sur Figma en s’inspirant de plateformes de e‑learning modernes.
  • Développement de l’interface avec React / JavaScript (routing, pages catalogue, tableau de bord, etc.).
  • Mise en place d’un parcours d’inscription avec création de compte et gestion des rôles (utilisateur, formateur, administrateur).
  • Intégration de Stripe pour le paiement sécurisé des formations.
  • Utilisation de Jira, Bitbucket et Git pour le suivi des tâches et la collaboration.

Back-end – Spring Boot

  • API back-end développée en Spring Boot pour centraliser la logique métier.
  • Gestion des comptes utilisateurs, des formations, des sessions et des inscriptions.
  • Exposition des données nécessaires aux datavisualisations du tableau de bord (statistiques de CA, nombre d’utilisateurs, taux de réussite, etc.).

Datavisualisation & fonctionnalités avancées

  • Création de dataviz pour les administrateurs : chiffre d’affaire, nombre d’utilisateurs, répartition par rôle, performances des formations.
  • Gestion des notes apprenant et de l’émargement (présences) pour le suivi pédagogique.
  • Interface de tableau de bord lisible et responsive, pensée pour les besoins métier.

Gestion de projet

  • Organisation du travail avec Jira (user stories, sprints, suivi de l’avancement).
  • Utilisation de Git et Bitbucket pour le versioning du code et les revues de merge.
  • Coordination entre la partie 3D, le front-end et le back-end pour garantir une expérience cohérente.
