Projet le plus ambitieux de l'année

TXLFORMA

Plateforme e-learning complète : vente de formations, salle 3D immersive, tableau de bord admin, paiement Stripe et gestion des rôles (utilisateur / formateur / admin).

Figma React Spring Boot Stripe Blender 3D Jira · Git
Pourquoi ce projet est le plus exigeant : fullstack (React + Spring Boot), paiement en ligne (Stripe), trois rôles métier distincts, modélisation 3D (Blender) intégrée au site, tableau de bord avec datavisualisations, et travail en équipe avec Jira/Git. Un livrable complet, de la maquette à la mise en production.

Contexte & objectif

Site de vente de formations en ligne : accueil, catalogue, inscription/connexion, tableau de bord selon le rôle (utilisateur, formateur, admin), paiement Stripe, suivi pédagogique (notes, émargement) et salle de classe 3D intégrée pour l’immersion.

Stack technique

Maquettes Figma · Front React / JavaScript · API Spring Boot · Paiement Stripe · Salle 3D Blender · Suivi Jira, Bitbucket, Git.

Design & front-end

Maquette sur Figma (inspiration e-learning). Développement React : accueil, catalogue, tableau de bord selon le rôle, inscription/connexion, gestion des rôles. Intégration Stripe pour le paiement des formations.

Modélisation 3D & intégration web

Salle de classe modélisée dans Blender (tables, chaises, PC, tableau, équipements). Textures et bake pour les perfs. Animations et caméras. Intégration au site avec contrôles : rotation, zoom, déplacement, vues (ex. « Professeur »).

Back-end & API

API Spring Boot : comptes, formations, sessions, inscriptions. Données pour le tableau de bord (CA, utilisateurs, taux de réussite) et métier (notes, émargement).

Tableau de bord & datavisualisation

Pour les admins : datavisualisations (chiffre d'affaires, utilisateurs par rôle, formations par catégorie, activités récentes). Sessions à venir, moyenne des sessions. Gestion des notes et de l'émargement.

Gestion de projet

Jira (user stories, sprints) · Git / Bitbucket pour le versioning et la revue de code. Coordination 3D, front et back pour un livrable cohérent, livré en conditions réelles.

Organisation en sprints & workflow

Méthodologie Agile / Scrum en 4 sprints : mise en place de l’environnement, création des fonctionnalités (CRUD, auth JWT, maquettes), ajout des fonctions clés (Stripe, 3D, tableaux de bord) puis intégration finale et déploiement. Workflow industriel Gitflow : 1 ticket Jira = 1 branche, pull request avec validations.

Ressources & documentation

Une présentation PDF complète détaille les sprints, l’architecture technique, Stripe, la 3D, l’hébergement (Vercel, Render, TiDB), le SEO et la politique de confidentialité.
